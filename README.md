Стэк - React, Node.js, Express.js, MongoDB, JavaScript, Redux Toolkit, Tailwindcss, FireBase, Axios

Приложение разработано как для админа, так и для обычного пользователя. 

Функционал пользователя:
-Регистрация/вход в аккаунт (дополнительная проверка через сервис FireBase на то, что почта действительно существует)
-Фильтрация товаров на главной странице по жанру
-Добавление товара в корзину, удаление товара
-Оформление заказа (заполнение необходимых полей) -> получение "чека" о заказе с индвидуальным номером

Функционал админа:
-Добавление новых книг
-Удаление книг
-Редактирование книг
-Просмотр количества сделанных заказов (и количество прибыли)

Все роуты защищены, для аутентификации используются токены 

Запуск проекта:
cd ./frontend - npm run dev
cd ./backend - npm run start:dev
