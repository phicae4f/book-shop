## 🚀 Основной функционал

### 🛒 **Клиентская часть (пользователь)**
- **Регистрация и авторизация** через JWT-токены
- **Каталог товаров** с детальным просмотром книг
- **Корзина покупок** с возможностью добавления/удаления товаров
- **Оформление заказов** с заполнением персональных данных
- **История заказов** — просмотр всех предыдущих покупок
- **Защищённые маршруты** — доступ к корзине и заказам только после авторизации

### 👑 **Административная панель**
- **Панель аналитики:** Общее количество товаров, сумма продаж, трендовые книги, количество заказов
- **Полный CRUD для товаров:** Добавление, редактирование, удаление книг
- **Управление заказами** — просмотр и обработка заказов пользователей
- **Разделение ролей** — отдельный вход для администратора

## 🛠 Технологический стек

### **Frontend**
- React
- JavaScript (ES6+)
- CSS для стилизации

### **Backend (самостоятельная разработка)**
- **Node.js + Express.js** (серверная платформа)
- **MongoDB** (NoSQL база данных)
- **JWT (jsonwebtoken)** — аутентификация
- **bcrypt** — шифрование паролей
- **REST API** архитектура

### **Безопасность**
- Хеширование паролей с **bcrypt**
- **JWT-токены** с ограниченным временем жизни
- Защищённые маршруты через middleware
- Валидация данных на сервере

Запуск приложения осуществляется через командную строку. Необходимо запустить два репозитория – папку «Frontend» и папку «Backend».

Перейдя в корзину, пользователь увидит все товары, ранее добавленные в нее. Пользователь может удалить конкретный товар, либо очистить всю корзину. Кликнув по ссылке «Продолжить покупки», пользователь вернутся на главную страницу. Для оформления заказа нужно нажать на кнопку «Заказать». После нажатия данной кнопки, пользователя перенесет на страницу оформления заказа, где необходимо заполнить данные о себе. При нажатии на кнопку «Оформить заказ», пользователь окажется на странице со всеми совершенными ранее покупкам.

Для того, чтобы войти как админ необходимо открыть панель админа на рисунке 33. После клика на кнопку, админу будет необходимо авторизоваться. При успешной авторизации админ будет перенаправлен на главную страницу, где ему доступна информация о количестве товаров, об общей сумме продаж, а трендовых книгах, о количестве заказов. Ему доступна боковая панель и кнопки, выделенные маркером. При нажатии на кнопку «Управление книгами» админу будет доступно обновление книги и ее удаление. Страница для обновления книги открывается при нажатии на кнопку «Редактировать». Если нажать на кнопку «Добавить книгу» на главной странице, то откроется окно с полями для добавления новой книги.

Все изменения происходят в реальном времени. После внесения любого изменения админ может проверять главную страницу. Сообщения о серверных ошибках выводятся в консоль и во вкладку Network.
Любые сообщения для пользователя (сообщения об успехе или об ошибке) выводятся в виде уведомлений.
